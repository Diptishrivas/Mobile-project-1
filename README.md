 # Notes App UI 

A clean and responsive Notes App UI built using React Native and Expo.

---

## Features

- Notes Listing Screen
- Note Editor Screen
- Dark/Light Theme Support
- Responsive Layout
- Search Notes UI
- FlatList for Notes
- KeyboardAvoidingView
- ImageBackground Header
- Pressable Buttons & Cards
- Modern Clean UI

---

## Tech Stack

- React Native
- Expo

---

## Components Used

- FlatList
- TextInput
- Pressable
- Switch
- KeyboardAvoidingView
- ImageBackground
- View
- Text

---

## Hooks Used

- useState()
- useColorScheme()
- useWindowDimensions()

---

## Styling

- StyleSheet.create()
- StyleSheet.compose()
- StyleSheet.flatten()

---

## Additional Improvements

- Responsive tablet layout
- Dark mode optimized UI
- Press animations
- Reusable components
- Clean typography and spacing

```bash
npm install
npx expo start
```
